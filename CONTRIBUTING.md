# Contributing to Git Tangle

Thank you for your interest in contributing.

## How to contribute

1. Open an issue or discussion for significant changes and align on direction
2. Fork the repository
3. Create a feature branch
4. Make your changes
5. Open a pull request with a clear description and motivation

## Coding principles

- Keep changes focused and incremental
- Prefer clear and maintainable shell over clever tricks
- Add tests or reproducible steps when contributing logic that affects behavior

## Commit messages

Use short, action‑oriented subjects. Conventional Commits are welcome.

Examples

```
feat(init): add interactive defaults for prefixes
fix(finish): handle missing remote by falling back to local merge
docs(readme): add configuration keys section
```
