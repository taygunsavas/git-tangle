# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our Pledge

We pledge to make participation in this project a harassment‑free experience for everyone, regardless of background, identity, or experience level.

## Our Standards

### Positive behavior

- Be welcoming, patient, and kind
- Give constructive feedback with empathy
- Focus on what's best for the project and the community
- Encourage beginners and contributors

### Unacceptable behavior

- Harassment, discrimination, or personal attacks
- Dismissing contributions with hostility or sarcasm
- Publishing others’ private information without explicit permission
- Sustained disruption of discussions

## Enforcement

Report unacceptable behavior to the maintainers through GitHub issues or by opening a private security advisory. The team will review and act as needed.
